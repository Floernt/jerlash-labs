# Rapport de sécurité - Contrôle avant envoi 0.1.0

Date : 2026-10-31. Parcours : renforcé (documents de dossier). Rédigé par l'auteur du code : à contre-vérifier par l'agent verificateur-securite ou par Florian (ADR-007, pas d'auto-certification).

## Modèle de menace retenu

| Menace | Mesure | Preuve |
|---|---|---|
| Exfiltration du document | Aucun module réseau importé ; analyse exécutée avec les fonctions réseau neutralisées | test_aucun_module_reseau_dans_le_code ; test_analyse_et_rapports_sans_reseau ; l'audit détecte 3 importations réseau plantées (test_l_audit_detecte_un_import_reseau_plante) |
| Altération du document analysé | Ouverture en lecture seule ; empreinte SHA-256 avant/après | test_octets_et_date_inchanges (octets et date de modification identiques) |
| Archive piégée (bombe de décompression, nombre d'éléments) | Limites de taille, de ratio et de nombre | test_bombe_de_decompression ; test_trop_d_elements |
| Entités XML (XXE, expansion) | Refus de toute partie contenant DOCTYPE ou ENTITY | test_declaration_d_entite_refusee ; test_entite_dans_une_partie_secondaire_donne_un_controle_en_erreur |
| Faux feu vert sur un fichier illisible | Statut « erreur » ou « incomplet », jamais « rien détecté » | test_fichier_absent ; test_fichier_texte_renomme ; test_archive_sans_document ; test_format_strict_non_pris_en_charge ; pièces protégée et tronquée |
| Injection dans le rapport HTML | Échappement de tout contenu issu du document ; CSP `default-src 'none'` dans le rapport | test_contenu_du_document_echappe_dans_le_html |
| Rapport joint par erreur | Rapport écrit dans un dossier distinct (Documents\Controle avant envoi), avertissement en tête du rapport | relecture du code (interface.py) |
| Dépendance compromise | Aucune dépendance hors bibliothèque standard | TIERS.md ; test d'audit des importations |
| Archive téléchargée altérée | Archive reproductible, empreinte SHA-256 publiée sur la fiche, procédure de vérification dans le guide | scripts/empaqueter.py --verifier ; scripts/verifier.py étape 3 |
| Secret commis dans le dépôt | Hook pre-commit et étape CI | scripts/detecter_secrets.py --auto-test (fausse clé détectée) |

## Points ouverts

| Niveau | Constat |
|---|---|
| à corriger | Le lanceur `.pyw` n'est pas signé ; l'utilisateur doit faire confiance à l'empreinte publiée. Un exécutable signé est envisageable plus tard. |
| remarque | `webbrowser.open` sur le rapport local lance le navigateur par défaut ; le rapport ne contient aucun script et aucune ressource externe. |

## Relecture indépendante (2026-10-31)

Un agent distinct de l'auteur a relu le code et reproduit chaque défaut sur des .docx construits pour l'occasion. Trois défauts bloquants (faux feu vert) et sept défauts à corriger ont été relevés, tous corrigés et couverts par `tests/test_relecture.py` :

| Niveau | Défaut | Correction |
|---|---|---|
| bloquant | Lien relatif ou serveur intranet classé « lien public » | Toute cible non http(s)/mailto, hôte sans point, IP privée ou suffixe interne : sensible |
| bloquant | Trait d'union insécable et apostrophe typographique non reconnus dans les termes | Normalisation des apostrophes, tirets, espaces ; noBreakHyphen rendu « - » |
| bloquant | Termes non cherchés dans codes de champ, textes alternatifs, customXml, SmartArt | Parcours de tous les textes et attributs de toutes les parties XML |
| à corriger | Erreur CRC ou compression non prise en charge : exception, code 1 | Conversion en « analyse impossible », code 2 ; filet général dans `analyser` |
| à corriger | Texte masqué hérité (basedOn, docDefaults, style de caractère) | Calcul des propriétés effectives |
| à corriger | Propriétés hors de docProps/ (.psmdcp) | Recherche par relation |
| à corriger | Deux rapports de même nom, le second écrasant le premier | Numérotation des rapports dans une session |
| à corriger | DOCTYPE en UTF-16 ou après 4 096 octets non refusé | Première lecture par expat avec refus des déclarations |
| à corriger | altChunk ignoré | Signalé dans « objets » ; termes : contenus non analysés listés |
| à corriger | Champ INFO LastSavedBy non signalé | Liste des champs révélateurs étendue |
| remarque | Macro au nom modifié, commentaires orphelins ou de casse différente | Détection par relation, type de contenu et nom insensible à la casse |
| remarque | Métadonnées XMP des JPEG | Détectées |

Remarques conservées sans correction : révisions dans numbering.xml désormais parcourues mais non testées sur un fichier Word réel ; consommation mémoire non mesurée sur des fichiers proches des limites (le cas aboutit à « erreur », pas à un faux feu vert) ; le niveau « rien détecté » reste possible sans liste de termes, et le verdict le signale.

Aucun point bloquant ouvert.
