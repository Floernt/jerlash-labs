# Code et contenus tiers

Aucun code tiers n'est repris dans cet outil.

L'idée d'un glossaire des termes définis d'un contrat s'inspire de la skill defined-terms-glossary du dépôt zenzen-sol/legal-prompts (licence MIT, consultée le 2026-10-31). Ni son texte ni son code ne sont repris : cette version se limite à un rapport, et ses règles de repérage, propres aux usages de rédaction francophones, sont propres à l'outil (ADR-008).

La lecture prudente des .docx et le registre Word reprennent la démarche des autres outils du même dépôt.

Dépendances d'exécution : aucune hors de la bibliothèque standard de Python (zipfile, xml.etree, tkinter, json, re).
