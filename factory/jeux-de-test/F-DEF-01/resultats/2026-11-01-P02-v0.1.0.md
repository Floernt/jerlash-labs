## Déroulement et neutralité du contrôle

1. Le jeu de contrôle a été rédigé en parallèle de l'outil par un agent sans accès au code ni au jeu de développement. Une précision de convention lui a été transmise avant qu'il ne termine, sans lien avec l'outil : un terme de l'article « Définitions » employé dans le préambule n'est pas un « emploi avant définition ».
2. La première exécution d'`evaluer.py` a affiché, avec le jeu de développement, les totaux du contrôle de la version brute : définis 48/50, divergents 3/5 en précision, sans définition 5/6 et 5/9, graphies 5/6, le reste exact.
3. Les règles ont ensuite été corrigées sur les seuls écarts du jeu de développement (3 écarts sur les termes sans définition). Ce réglage a retiré une fausse alerte du contrôle (5/9 → 5/8).
4. Le rapport de l'agent rédacteur citait quelques pièges de son jeu (« (RGPD) », un terme entre guillemets non défini, un pluriel sur deux mots). Aucune règle n'a été écrite d'après eux ; ils sont mentionnés ici pour la transparence.
5. La relecture indépendante a conduit à 18 corrections, réglées sur des démonstrations propres au relecteur, qui n'avait pas accès au jeu de contrôle. Les totaux du contrôle n'ont pas changé.

Les écarts détaillés du contrôle n'ont pas été affichés. Le jeu de contrôle reste utilisable pour la prochaine version ; un second jeu sera nécessaire dès qu'une règle sera réglée d'après lui.
