# Mémoire de la Factory

La mémoire vit dans `factory/memoire/`. `index.md` liste les fichiers avec une ligne de description.

## Enregistrer (fin de session)

Parcours la session et retiens uniquement ce qui est :
- durable : utile dans une session future ;
- non évident : un agent ne le saurait pas sans qu'on le lui dise ;
- utile : change une manière de faire ou évite une erreur.

Exemples : une décision de Florian et sa raison, une erreur rencontrée et sa solution, une préférence exprimée, une limite d'une bibliothèque découverte en test.

Écris dans le fichier thématique existant ou crée-en un (moins de 50 lignes, puces, liens [[nom]] vers les fichiers liés). Mets à jour index.md.

Jamais de donnée de dossier, de clé ou d'information personnelle.

## Nettoyer (revue)

Lis toute la mémoire. Propose : suppressions de notes obsolètes, fusions de doublons, raccourcissements, liens manquants. Présente toutes les modifications et attends l'accord avant de les appliquer.
