Clôture la session de travail.

1. Résume ce qui a été fait pendant la session.
2. Ajoute une entrée en haut de LOG.md selon le format indiqué dans ce fichier.
3. Retire de BACKLOG.md les tâches terminées (ce qui est livré entre dans CHANGELOG.md) et ajoute les nouvelles.
4. Si une décision structurante a été prise, vérifie qu'elle figure dans docs/decisions.md.
5. Vérifie qu'aucun fichier contenant une clé API ou une donnée réelle n'est prêt à être commité (git status, git diff --cached).
6. Propose un message de commit, sans committer.
